# Jubileu
 
Dependencias:

Git
Node.Js


Antes de executar o programa use o código no terminal: npm install



Para executar o programa use node index.js


Caso o programa não execute e apresente erros relacionados ao whatsapp-web ou qr-code-terminal delete os arquivos dentro de "packages" e reinstale eles usando os comandos npm install qrcode-terminal e npm install whatsapp-web.js
